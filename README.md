# Pengembangan Aplikasi Website

Kumpulan tugas dan proyek dari mata kuliah **Pengembangan Aplikasi Website** program studi **Teknik Informatika** **Institut Teknologi Sumatera**.

## 📚 Deskripsi

Repository ini berisi berbagai tugas dan proyek yang diberikan dalam mata kuliah Pengembangan Aplikasi Website. Setiap folder atau file di repository ini merepresentasikan tugas atau proyek tertentu dengan konsep-konsep pengembangan web yang berbeda.

## 🎯 Tujuan

- Mengumpulkan semua tugas dan proyek dalam satu tempat
- Mendokumentasikan proses pembelajaran pengembangan aplikasi website
- Menunjukkan progress dan kemampuan dalam web development
- Menyimpan referensi untuk pembelajaran di masa depan

## 📁 Struktur Repository

Setiap folder di repository ini berisi:
- **Source code** - File-file aplikasi web
- **Documentation** - Penjelasan atau dokumentasi tugas
- **Assets** - File pendukung seperti gambar, CSS, atau database

## 💻 Teknologi yang Digunakan

Repository ini menggunakan berbagai teknologi web development, termasuk:
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP, Python, atau sesuai requirement tugas
- **Database**: MySQL, PostgreSQL, atau NoSQL
- **Framework/Library**: Sesuai dengan tugas yang diberikan
